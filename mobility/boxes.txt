# Taught motions - one line per box.
#
# Instead of working an angle out from the map and dividing by a motor
# speed, each box says plainly how long to run each motor. You tune the
# numbers by watching the machine, and it repeats exactly what you tuned.
# No degrees per second, no overshoot from a bad estimate.
#
# It assumes the head starts from the same place every run, so set the
# datum (z at the prompt) before you begin. After spraying, each motion
# is run backwards to put the head back where it started, ready for the
# next box.
#
#   rail_mm   where to put the rail first, absolute, from home
#   pan_s     seconds to drive pan. NEGATIVE means the other way.
#   tilt_s    seconds to drive tilt. NEGATIVE means the other way.
#   spray_s   seconds to hold the valve open
#
# A box with no line here falls back to the computed aim.
